# 08. User experience

## Principles
- Simple enough for non-technical users. No model names, tokens or endpoints on main screens; advanced options behind one link.
- Connecting an AI or a service should feel like joining Wi-Fi.
- AI work is visible when you want it, invisible when you do not.
- Every AI action can be approved, seen and undone.

## Screens (concept designed, see concept canvas)
1. Setup flow: welcome + hardware check; "Where should your assistant think?" (On this computer / Connect an AI account, local greyed out on Lite hardware); provider picker (Claude, ChatGPT, Gemini, Muse "Soon", Other); sign in (OAuth or API key); auto connection test; done.
2. Desktop: top bar with brain status pill; dock; command bar (Super + Space).
3. Connections window: AI interfaces tab (external AI apps, phone, custom UI) and Tools tab (built-in tools, one-click services, add MCP server by URL).
4. Settings > Brain: current brain, online AI card, Switch brain dialog with "what changes", offline fallback checkbox, privacy slider (Nothing personal / Only what the task needs / Full context), ask-before-sending checkbox.

## On Fedora (Stage A: look and layout)
Built 2026-10-12 in `system_files/`, applied to every new user (test loop: `ui/README.md`).

| Preview | On the image |
| --- | --- |
| Design tokens (`globals.css`) | Color schemes `SIOS Light` and `SIOS Dark` (selection and focus in the assistant blue, warnings in ember) |
| Instrument Sans, Jost, JetBrains Mono | Shipped in `/usr/share/fonts/sios`, set as the system fonts |
| 36px top bar: logo, wordmark, status | Top panel: logo menu, app menu, the SIOS wordmark (our widget), tray, clock with date |
| Floating dock | Floating bottom panel sized to its apps: Files, Browser, Store, Activity, Settings (the Ask orb joins in Stage B) |
| Tunnel wallpaper | `SIOS-Tunnel`, light and dark, drawn from the same code as the preview |
| Boot wordmark | Splash screen: tunnel, wordmark, tagline |
| Lock and login | Our wallpaper (Fedora 44's login screen only allows the wallpaper to change) |

Not in Stage A: the boot-time Plymouth logo (needs the initramfs rebuilt, which is a separate, riskier step), stronger glass blur and rounded window corners (stock KDE only, by choice), and our own apps (Ask bar, brain pill, approval prompt: Stage B).
