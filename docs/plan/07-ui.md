# UI concept

Already designed as a mockup. Must stay very simple for non-technical users. Polish comes later.

## Setup flow
1. Welcome screen with hardware check.
2. "Where should your assistant think?": On this computer / Connect an AI account. Local is greyed out on Lite hardware.
3. Provider picker: Claude, ChatGPT, Gemini, Muse (marked "Soon"), Other.
4. Sign in with OAuth or paste an API key.
5. Automatic connection test.
6. Done.

## Desktop
- Top bar with a "Brain: local" status pill.
- Left dock.
- Centered command bar (Super + Space).
- Connections window with two tabs:
  - **AI interfaces**: external AI apps.
  - **Tools (MCP)**: built-in tools, one-click services, "add your own MCP server by URL".

## Settings > Brain
- Current brain.
- Online AI card.
- "Switch brain" dialog explaining what changes.
- "Use this computer when offline" fallback checkbox.
- Privacy slider for what can be shared with online AI.
- "Ask before sending to online AI".
