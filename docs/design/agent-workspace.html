The agent Workspace

Mockup only, for the owner's approval (D101, D106). Names, files and numbers are made up. Instead of another desktop, each agent gets one Workspace window laid out from what it is doing: its goal and plan, its live output, the files it is touching, what it knows, its changes, and a terminal to take the wheel. Panes resize and hide; the layout is remembered per agent.

2. Places: which of your folders an agent can see

A new way to give a coding agent access. Pick folders on your drive, choose where they appear in its workspace and whether it may change them. Nothing else in your home is visible to it. Sensitive and off-limits folders can't be picked. Adding a place asks for your password and is logged. A read-and-write place that isn't a git project is snapshotted before each task, so its changes can be undone.
