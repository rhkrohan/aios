The agent Workspace

Mockup only, for the owner's approval (D101, D106, D107). Names, files and numbers are made up. One window per agent instead of another desktop. The middle has three tabs: Live (what it's doing now), Review (read, comment on and approve its changes) and Desktop (its own desktop, which you and it can both use). Around them: its goal and plan, the files it's touching, and what it knows.

1. Live

What it's doing right now, as cards: what it says, every edit as a diff, every command with its output, and questions with a reply box. Files light up on the right as it reads (blue) or changes them (green).

2. Review

A proper code review, like a pull request, but on your computer. Files on the left with a check for each one you've read; the diff in the middle with line numbers; click any line to comment. Your comments go back to Pip as its next task with one click. Open folder opens its copy of the project in Files; Open in editor opens it in your code editor, read-only, so you can run it or look around. When you're happy, Approve and merge brings it into your project (asks for your password).

3. Desktop

Pip's own desktop, inside its sandbox and shown live in this panel: its browser, its files, its terminal. You and Pip can both use it. Its cursor carries its colour and name, yours is yours. Take control hands you the mouse and keyboard and pauses Pip's hands; Give it back lets it continue. It's a separate desktop, so Pip can never see or touch yours, and nothing you type here reaches your own apps.

4. Places: which of your folders an agent can see

Pick folders on your drive, choose where they appear in its workspace and whether it may change them. Nothing else in your home is visible to it; off-limits and Sensitive folders can't be picked. Adding one asks for your password and is logged. A read-and-write folder is copied before each task so you can put it back, and SIOS tells you if the agent leaves anything that can run. Git projects can only be read (make one the agent's project instead).
